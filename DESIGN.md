# Website design profile

The authoritative OpenE2EE design contract lives in
[`open-e2ee/design`](https://github.com/open-e2ee/design/blob/main/DESIGN.md).

- Shared release: `@open-e2ee/design` v0.8.0, pinned in `package.json` as a
  tagged tarball
- Surface: public marketing and engineering editorial
- Density: spacious and expressive
- Theme: `light`, `dark`, and `system` through the shared `.dark` root contract
- Local ownership: page composition, marketing components, editorial layouts,
  and product-specific copy

`src/styles/global.css` is the whole stylesheet. It imports `fonts.css`,
`tokens.css`, and `wordmark.css` from `@open-e2ee/design` and then styles this
site's own components. The compatibility layer that once mapped unprefixed
variables onto shared tokens — `src/styles/design-system.css` — has been
removed: every declaration uses semantic `--oe-*` variables directly, and no
mode-specific color is written literally, because the theme contract in
`@open-e2ee/design` owns light and dark. The one exception is the pair of
`<meta name="theme-color">` values in `BaseLayout.astro`, which the browser
requires as literals.

Brand assets under `public/brand` are generated by `oe-design`; do not edit
them directly. `npm run brand:check` fails the build if they drift from the
pinned release.

Taglines are still formally proposed rather than signed off, so the footer
carries the annotation the design contract requires. See `docs/content-and-voice.md`
in the design repository.
